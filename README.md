# 安全管理数据工作台

单机运行的安全管理数据平台。双击 **`启动工作台.bat`** 即可使用，数据保存在本机，无需联网、无需数据库。

**支持局域网远程查看**：双击 `启动局域网查看.bat`，同一办公网内的手机、其他电脑输入窗口显示的地址即可查看看板（只读），数据每 30 秒自动刷新。

## 功能

| 模块 | 内容 |
|---|---|
| 综合看板 | 20 项 KPI、6 个图表、逾期与到期提醒清单 |
| 隐患排查治理 | 登记 → 整改 → 验收 → 关闭 全流程闭环，逾期自动标红 |
| 风险分级管控 | LEC 法自动计算风险值 R 与四色分级 |
| 安全疑虑 | 员工反映的安全顾虑，核实后转隐患或答复关闭，支持匿名 |
| 事故事件管理 | 按公司标准分 6 大类（安全疑虑/未遂/一般事件/急救箱/医疗处置/一般事故），急救箱与医疗处置细分为 A/B/C 级 |
| 教育培训 | 三级教育、专项培训、考核记录 |
| 人员资质证照 | 特种作业证台账，到期前 30 天自动提醒 |
| 消防设施器材 | 点检周期管理，自动推算下次点检日期 |
| 设备管理 | 特种设备（吊车/叉车/电梯/储气罐）、表阀（压力表/安全阀/流量计）、其他类，检验到期提醒 |
| 应急演练 | 演练计划、实施、评估闭环 |
| 承包商管理 | 准入审核、资质有效期、违章记录 |
| 作业许可票 | 八大作业票、监护人、时效跟踪 |

全部模块支持 Excel 导入导出、搜索筛选排序分页。

## 快速开始

1. 确认已安装 Python 3.10+（安装时勾选 Add Python to PATH）
2. 双击 `启动工作台.bat`（仅本机）或 `启动局域网查看.bat`（手机/其他电脑可看）
3. 浏览器自动打开，开始使用

首次运行会自动安装 openpyxl 依赖。

### 三种启动方式

| 脚本 | 访问范围 | 远程权限 |
|---|---|---|
| `启动工作台.bat` | 仅本机 | — |
| `启动局域网查看.bat` | 局域网 | 只读（可设密码） |
| `启动工作台.bat --lan-edit` | 局域网 | 可编辑 |

## 数据

- 数据位置：`data/*.json`
- 备份：界面左下角「备份全部数据」可下载 zip；系统也会自动备份到 `data/backup/`
- 演示数据：`python app\seed.py --force` 重新生成，`python app\seed.py --clear` 清空

## 导出

- **HTML 报表**：看板右上角「导出 HTML 报表」，生成单文件报表（含全部图表），可离线查看、打印 PDF
- **Excel**：各模块工具栏「导出 Excel」，导出当前筛选结果
- 命令行导出：`python app\export_html.py --out 报表.html`

## 技术栈

Python 3 标准库（http.server）+ openpyxl + 原生 HTML/CSS/JS（Canvas 手绘图表），零前端框架依赖，完全离线可用。

## 自检

```bash
python app\selftest.py          # 后端逻辑 40 项
python app\httptest.py 8799     # 接口端到端 33 项
python app\lantest.py 8795      # 局域网/只读 17 项
node app\uitest.mjs 8801 8800   # 浏览器冒烟 49 项（需先启动服务）
node app\lantest-ui.mjs 8811 8810  # 只读界面 15 项（需以 --lan 启动服务）
```
