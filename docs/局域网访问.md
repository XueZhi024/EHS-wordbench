# 局域网远程访问指南

让同一办公网内的**手机、平板、其他电脑**打开这个看板，数据实时同步。

---

## 一、最快上手（三步）

### 第 1 步：在放数据的电脑上，双击 `启动局域网查看.bat`

窗口会显示类似这样的地址：

```
================================================================
  安全管理数据工作台  v1.1.0
================================================================
  本机访问：http://127.0.0.1:8765/
  局域网访问（同一办公网内的手机/电脑输入以下地址）：
            http://192.168.20.154:8765/
  远程权限：只读（推荐）
  提示：Windows 防火墙首次可能弹窗，请点「允许访问」
================================================================
```

### 第 2 步：防火墙点「允许访问」

首次启动时 Windows 会弹出防火墙提示，**勾选「专用网络」并点「允许访问」**。如果当时点了「取消」，看下一节的「防火墙没放行怎么办」。

### 第 3 步：手机/其他电脑打开浏览器，输入上面那个 `http://192.168.x.x:8765/`

完成。手机连的是同一个 Wi-Fi，就能看到实时数据。

---

## 二、两种访问模式

| 模式 | 启动方式 | 远程能做什么 | 适合场景 |
|---|---|---|---|
| **仅本机**（默认） | 双击 `启动工作台.bat` | 外部完全访问不到 | 只有自己用 |
| **局域网只读**（推荐） | 双击 `启动局域网查看.bat` | 只能看，不能改 | 给领导、同事看数据 |
| **局域网可编辑** | `启动工作台.bat --lan-edit` | 可以新增、编辑、流转 | 多人协同录入 |

**本机始终可编辑**——只有远程访问才受限。你坐在自己电脑前操作，一切照旧。

### 只读模式会做什么

- 隐藏「新增」「导入 Excel」「下载模板」按钮
- 列表行只保留「详情」，没有「编辑」「删除」「流转」
- 详情弹窗里没有操作按钮
- 侧栏底部提示「只读模式 · 如需修改请在本机操作」
- **保留**「导出 Excel」和「搜索筛选」

即使有人绕过界面直接调接口，服务端也会返回 403 拒绝。

## 三、设置访问密码

局域网里任何人知道地址就能看，如果数据敏感，建议设密码：

双击 `启动局域网查看.bat` 后，窗口会问：

```
设置访问密码（直接回车表示不设密码）：
```

输入密码后回车即可。之后远程访问者会先看到登录页，输入密码才能进入。

- 密码只存在内存里，关掉窗口就没了，下次启动重新设置
- 本机访问不需要密码
- 登录状态保持 24 小时

---

## 四、动态刷新

看板右上角有「自动刷新」开关，默认开启，**每 30 秒自动更新一次**：

- 你在这台电脑录入数据，手机上 30 秒内就能看到
- 页面切到后台时暂停刷新，切回来继续
- 打开弹窗编辑时暂停刷新，不会打断你操作
- 也可以手动点「刷新」立即更新

## 五、常见问题

### 手机打不开怎么办

按顺序排查：

1. **确认在同一个网络** —— 手机连的是不是同一个 Wi-Fi？（不是 4G/5G，不是访客网络）
2. **确认地址没输错** —— 注意是 `http://` 不是 `https://`，端口号 `8765` 不能漏
3. **确认服务窗口还开着** —— 电脑上那个黑色命令行窗口不能关
4. **防火墙没放行** —— 见下一节
5. **公司网络隔离** —— 有些公司的 Wi-Fi 开了「AP 隔离」，设备之间不能互访，需要找 IT 关掉

### 防火墙没放行怎么办

如果首次弹窗时点了「取消」，手动加一条规则：

以**管理员身份**打开 PowerShell，执行：

```powershell
New-NetFirewallRule -DisplayName "安全管理数据工作台" -Direction Inbound `
  -Protocol TCP -LocalPort 8765 -Action Allow -Profile Private
```

删除规则：

```powershell
Remove-NetFirewallRule -DisplayName "安全管理数据工作台"
```

### 地址里的 IP 变了

局域网 IP 通常是路由器动态分配的，电脑重启后可能变。三个办法：

1. 每次启动看窗口里显示的新地址
2. 在路由器里给这台电脑设置「静态 IP / DHCP 绑定」
3. 用电脑名访问：`http://电脑名:8765/`（如 `http://DESKTOP-ABC:8765/`）

### 端口被占用

窗口里显示的地址才是真实地址，会自动顺延到 8766、8767……以窗口显示为准。

也可以手动指定：

```bash
python app\server.py 9000 --lan
```

### 想让外网也能看（在家、出差）

当前版本只支持局域网。外网访问需要额外工具，常见两种：

- **Cloudflare Tunnel**（免费、不用改路由器）：
  装 `cloudflared`，执行 `cloudflared tunnel --url http://localhost:8765`，
  会给你一个 `https://xxx.trycloudflare.com` 的临时地址。
- **frp / 花生壳**：需要有公网服务器或购买服务。

⚠️ **外网暴露前务必设密码**（`--password`），并且建议保持只读模式。公司安全数据外泄风险要自己评估。

### 多人同时访问会卡吗

不会。服务是多线程的，十几个人同时看完全没问题。数据文件写入有锁保护，不会冲突。

## 六、安全提醒

这个工作台**没有用户体系**，只有「本机 / 远程」两级区分：

- ✅ 局域网内只读，足够应对「给同事看数据」的场景
- ⚠️ 不要在公共 Wi-Fi（咖啡厅、酒店）下开 `--lan`
- ⚠️ 不要把端口直接映射到公网而不设密码
- ⚠️ 数据里有承包商联系方式等信息，按公司规定管理

如果需要「谁能看哪个部门」这种细粒度权限，需要另外开发用户体系，不在当前版本范围。

## 七、命令速查

```bash
# 仅本机（默认）
python app\server.py

# 局域网只读（推荐）
python app\server.py --lan

# 局域网可编辑
python app\server.py --lan --remote-edit

# 局域网 + 密码
python app\server.py --lan --password 你的密码

# 指定端口
python app\server.py 9000 --lan

# 不自动打开浏览器
python app\server.py --lan --no-browser
```

对应的双击脚本：

| 文件 | 作用 |
|---|---|
| `启动工作台.bat` | 仅本机 |
| `启动局域网查看.bat` | 局域网只读（会询问是否设密码） |
| `启动工作台.bat --lan-edit` | 局域网可编辑 |
