# 事件等级划分标准与数据导入

本文说明公司《事件等级划分标准》在工作台中的落地方式，以及事故台账数据的导入方法。

---

## 一、事件等级体系

工作台按公司标准把事件分为 **6 大类**，其中 3 类还要细分为 **A/B/C 级**：

| 大类 | 是否细分 | 判定要点 |
|---|---|---|
| 安全疑虑 | 否 | 尚未发生事故，但可能引发事故的不安全因素 |
| 未遂事件 | 否 | 未造成伤害、疾病和损失，但非常接近发生 |
| 一般事件 | 否 | 造成企业直接经济损失（工业安全/道路交通/火灾/其他） |
| 急救箱事件 | **A/B/C** | 按就医程度与休假天数 |
| 医疗处置事件 | **A/B/C** | 按停工休假天数 |
| 一般事故 | **A/B/C** | 按伤亡人数与经济损失 |

---

## 二、细分等级判定标准

### 急救箱事件（医疗费用 1500 元以下）

| 等级 | 判定标准 |
|---|---|
| **A 级** | 需到医院检查，停工休假 **3 天以内**（含 3 天） |
| **B 级** | 需到医院进行清洗、消毒、清创、包扎等医疗处理 |
| **C 级** | 使用急救箱内物品进行消毒、清创、包扎，**不影响工作** |

### 医疗处置事件

| 等级 | 判定标准 |
|---|---|
| **A 级** | 停工休假 **15 天以上** |
| **B 级** | 停工休假 **15 天以内**（含 15 天） |
| **C 级** | 停工休假 **3 天以内**（含 3 天） |

### 一般事故

| 等级 | 判定标准 |
|---|---|
| **A 级** | 3 人以下死亡，或 3–10 人重伤，或 10 人以上轻伤，或 100–1000 万元损失 |
| **B 级** | 3 人以下重伤，或 3–10 人轻伤，或 10–100 万元损失 |
| **C 级** | 3 人以下轻伤，或 10 万元以下损失 |

## 三、工作台中的字段

「事故事件管理」模块新增了三个字段：

| 字段 | 说明 |
|---|---|
| **事件大类** `level1` | 必填，六选一 |
| **细分等级** `grade` | 仅急救箱/医疗处置/一般事故显示，A/B/C 级 |
| **等级说明** `levelDesc` | 自动计算，显示该等级的具体判定标准 |

**条件显示**：选「未遂事件」时，细分等级字段自动隐藏（因为不需要）；选「急救箱事件」时才出现。

**等级说明自动生成**：选完大类 + 等级后，系统自动显示对应的判定标准文字，录入时不用记标准。

## 五、等级自动推断规则

导入时按以下逻辑推断等级（源数据没有 A/B/C 字段）：

### 急救箱事件

```
有休假天数 > 0        → A 级
描述含"医院/就医"      → B 级
描述含"创可贴/自行处理" → C 级
有医疗费用 > 0        → B 级
其他                 → C 级
```

### 医疗处置事件

```
休假 > 15 天    → A 级
休假 4–15 天    → B 级
休假 ≤ 3 天     → C 级
```

### 事件类型推断

```
描述含"着火/起火/明火/冒烟/引燃" → 火灾爆炸
描述含"叉车/行车/吊车/高速/司机" → 交通事故
大类为未遂事件                    → 未遂事件
描述含"设备/损坏/故障/破损"       → 设备事故
其他                             → 人身伤害
```

## 六、如何导入新数据

### 方式一：界面导入（单条或少批量）

左侧「事故事件管理」→「＋ 新增」→ 选择事件大类 → 需要时选细分等级。

系统会自动显示等级说明，按标准判断即可。

### 方式二：Excel 批量导入

1. 点「下载模板」拿到标准模板
2. 按模板填写（表头不要改）
3. 点「导入 Excel」

模板里「事件大类」「细分等级」都是下拉候选，按标准选。

### 方式三：从公司台账批量导入（推荐用于历史数据）

如果拿到的是公司格式的 Excel，用专用脚本：

```bash
python app\import_incidents.py "文件1.xlsx" "文件2.xlsx"           # 预览
python app\import_incidents.py "文件1.xlsx" "文件2.xlsx" --commit  # 导入
python app\import_incidents.py "文件1.xlsx" "文件2.xlsx" --commit --reset  # 先清空
```

脚本会自动：判断等级、推断类型、映射部门、提取受伤部位、计算损失工日。

**务必先预览**，确认分布合理后再加 `--commit`。

## 七、关于「1500 元」的边界

公司标准里急救箱事件定义是「医疗费用 **1500 元以下**」，超过应归医疗处置事件。

当前导入是按**原始台账的分类字段**（急救箱/医疗处置）来定的，没有用费用重新判定。原因是：

- 原始台账的分类是公司审批时确定的，应以它为准
- 个别记录费用超 1500 元（如缝 4 针 1663 元），但原台账归为急救箱

如果要以费用为准重新分类，告诉我，我改脚本重跑。

## 八、看板统计口径

看板「事故/事件」区域新增了这些指标：

| 指标 | 计算口径 |
|---|---|
| 事故/事件 | 统计期内全部事件条数 |
| 急救箱事件 | `level1 = 急救箱事件` 的条数 |
| 医疗处置 | `level1 = 医疗处置事件` 的条数 |
| 未遂事件 | `level1 = 未遂事件` 的条数 |
| 一般事件 | `level1 = 一般事件` 的条数 |
| 受伤人数 | `persons` 字段去重计数 |
| 损失工日 | `lossDays` 求和 |
| 医疗费用 | `medicalCost` 求和 |

「事件等级分布」图表按六大类分组显示。
