# 安全管理数据工作台 — 使用说明

版本 1.0.0　｜　单机本地运行，数据保存在本机

---

## 一、快速开始

### 1. 启动

双击目录下的 **`启动工作台.bat`**。

- 会弹出一个黑色命令行窗口，显示访问地址（通常是 `http://127.0.0.1:8765/`）；
- 浏览器会自动打开工作台页面；
- **关闭这个命令行窗口 = 停止服务**，数据已自动保存，不会丢失。

如果浏览器没有自动打开，手动把窗口里显示的地址复制到浏览器地址栏即可。

### 1.1 手机或其它电脑查看

双击 **`启动局域网查看.bat`**，窗口会显示一个 `http://192.168.x.x:8765/` 形式的地址，同一办公网内的手机/电脑输入这个地址即可查看（只读，每 30 秒自动刷新）。

详见 [局域网访问指南](局域网访问.md)。

### 2. 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 |
| Python | 3.10 或更高版本（首次运行会自动检查） |
| 依赖库 | openpyxl（仅用于 Excel 导入导出，`启动工作台.bat` 会自动安装） |
| 浏览器 | Chrome / Edge / Firefox 任一现代浏览器 |
| 网络 | **不需要联网**，全部数据在本机 |

> 如果提示「未找到 Python」，请到 python.org 下载安装，安装时勾选 **Add Python to PATH**。

### 3. 端口被占用怎么办

服务默认使用 8765 端口，被占用时会自动顺延到 8766、8767……实际地址以命令行窗口显示为准。

## 三、各模块使用

### 3.1 综合看板

- **顶部筛选条**：选择统计时间段（默认本年）和部门，点「查询」刷新；点「重置」回到默认范围。
- **KPI 卡片**：14 个核心指标。带红色左边框的是需要重点关注的异常项。
- **四个图表**：隐患月度趋势（折线）、风险四色分布（柱状）、隐患类别分布（条形）、事故类型分布（饼图）。鼠标悬停可看数值。
- **提醒清单**：逾期未整改隐患、证照到期、消防点检逾期、作业票临期。**点击任意一行会跳转到对应台账并自动搜索该条记录**。

### 3.2 隐患闭环（隐患排查治理）

完整流程：

```
登记（新增）→ 开始整改 → 提交验收 → 验收通过 → 已关闭
                              ↓
                          验收不通过 → 回到「整改中」
```

**操作方法**：
1. 点右上角「＋ 新增」填写隐患信息，保存后状态为「待整改」；
2. 在列表行末点「流转 ▾」，选择「开始整改」；
3. 整改完成后点「流转 ▾」→「提交验收」，此时**必须填写整改完成日期**；
4. 验收人点「流转 ▾」→「验收通过」，**必须填写验收日期和验收人**，状态变为「已关闭」；
5. 验收不通过则选「验收不通过」，状态回到「整改中」。

**自动判断**：未关闭且已超过整改期限的隐患，列表「逾期」列显示红色「逾期」徽标，看板「逾期未整改」卡片同步计数。

### 3.3 风险分级管控

- 填写「可能性 L」和「严重性 S」（都是 1–5 的整数），系统自动计算 **风险值 R = L × S** 并判定等级：

| R 值 | 等级 | 颜色 | 管控要求 |
|---|---|---|---|
| ≥ 20 | 重大风险 | 红 | 立即整改，公司级管控 |
| 15–19 | 较大风险 | 橙 | 限期整改，部门级管控 |
| 9–14 | 一般风险 | 黄 | 计划整改，班组级管控 |
| < 9 | 低风险 | 蓝 | 日常巡查，岗位级管控 |

- 修改 L 或 S 后，R 值与等级会**自动重算**。
- 看板「风险四色分布」直接读取这里的分级结果。

### 3.4 安全疑虑

**这是什么**：员工反映的、还**不一定构成隐患**的安全顾虑。比如「食堂后厨好像有燃气味」「夜班照明太暗」——这类主观感受需要先核实，确认属实才转为隐患整改。

**和隐患的区别**：

| | 安全疑虑 | 隐患 |
|---|---|---|
| 性质 | 我觉得这里不安全 | 已确认的问题 |
| 谁来提 | 任何人，可以匿名 | 检查、巡检 |
| 怎么处理 | 先核实，再决定去向 | 直接整改 |
| 最终去向 | 属实 → 转隐患；不属实 → 说明后关闭 | 整改验收后关闭 |

**操作流程**：

1. **登记**：点「＋ 新增」，填写疑虑内容、反映渠道、所属部门、处理时限。反映人可以留空（匿名）。
2. **开始核实**：行末「流转 ▾」→「开始核实」，状态变「核实中」。
3. **分两种情况**：
   - **属实** → 先到「隐患排查治理」新建一条隐患（走完整的隐患登记流程），拿到隐患编号后回来点「流转 ▾」→「转隐患」，**填核实结论和隐患编号**（两项都必填）。
   - **不属实** → 点「流转 ▾」→「答复并关闭」，**填答复日期和答复内容**（必填，保证反映人得到反馈）。
4. 如果核实后发现还需要补充信息，可以「退回待核实」。

**自动提醒**：

- 超过「处理时限」未关闭的，列表「超期」列显示红色「逾期」
- 「剩余」列显示还剩几天，负数表示已超期（如「超2天」）
- 「反馈」列显示「待答复 / 已答复 / 已办结」
- 看板有「待处理安全疑虑」提醒清单，点进去直接定位

**为什么转隐患要手动填编号**：系统不自动创建隐患，是为了强制走完整的隐患登记流程（责任人、期限、等级都得填全）。这样从疑虑到隐患的链条清晰，能追溯是谁提的、什么时候核实的、转成了哪个隐患。

### 3.5 事故事件

- 记录事故、未遂、险兆事件；必填直接原因和纠正预防措施。
- 状态流转：调查中 → 整改中 → 已结案（结案必须填结案日期，且不能早于发生时间）。
- 看板统计：事故起数、损失工日、直接经济损失、事故类型分布。

### 3.6 教育培训

- 登记培训主题、类型、日期、学时、参训人数、考核通过率。
- 状态：计划中 → 已完成 / 已取消。
- 看板「培训场次」「培训完成率」「参训人次」由此统计。

### 3.7 人员资质证照

- 登记特种作业证、资格证等，**必须填到期日期**。
- 系统自动计算「剩余天数」和「到期提醒」：
  - 红色「已过期」：已过到期日
  - 橙色「30天内到期」：需要安排复审
  - 绿色「正常」
- 到期前 30 天的证照会出现在看板提醒清单。

### 3.8 消防设施器材

- 登记灭火器、消火栓、报警系统等，设置点检周期。
- 填写「最近点检日期」后，系统自动算出**下次点检日期**；超过下次点检日期仍未更新，标记为「点检逾期」。
- 点检周期：每月按 30 天、每季按 91 天、每半年按 182 天、每年按 365 天计算。

### 3.9 设备管理

设备台账按**三大类**组织，页面上方有分类页签，点一下只显示该类设备：

| 大类 | 包含设备 |
|---|---|
| 特种设备类 | 吊车、叉车、电梯、储气罐（另有锅炉、压力容器、起重机械） |
| 表阀类 | 气包压力表、气罐压力表、安全阀、流量计 |
| 其他类 | 空压机、锅炉、除尘系统等其它设备 |

**表单会根据设备类型自动切换字段**——选「叉车」只出现使用登记证号、额定载荷；选「电梯」换成额定速度；选「安全阀」换成校验周期、校验日期、校验结果。不用填无关的字段。

**各类的重点要求**：

- **特种设备类**：使用登记证号和下次定期检验日期**必填**（这是法规要求，系统会拦）；
- **表阀类**：校验周期**必填**，填了最近校验日期后自动算出下次校验日期；
- **其他类**：记录制造单位和投用日期即可。

**到期提醒**：填了「检验有效期至」，系统自动算剩余天数并标色——已过期红色、30 天内到期橙色。停用和报废的设备不再提醒。看板会汇总所有到期的设备。

**状态流转**：在用 ⇄ 备用 ⇄ 停用，在用/备用 → 维修中 → 在用，任意状态 → 已报废。

### 3.10 应急演练

- 状态流转：计划中 → 已实施（需填实际日期）→ 已评估（需填演练评估）→ 已关闭。

### 3.11 承包商管理

- 审核通过前状态为「待审核」。
- **准入校验**：状态改为「已准入」时，安全协议不能是「未签订」，且资质有效期不能已过期。
- 违章次数累计，看板汇总所有承包商的违章总数。

### 3.12 作业许可票

- 登记八大作业票，填写作业时间区间、监护人、安全措施。
- 系统自动判断时效：「进行中」「24小时内到期」「已超期」。
- 临期和超期的作业票会出现在看板提醒清单。

## 四、Excel 导入导出

### 4.1 导出

在任意模块点「导出 Excel」：

- 导出**当前筛选结果**（如果搜索或筛选过，只导出筛选后的记录）；
- 文件包含两个工作表：数据页 + 「填写说明」页（列出每个字段的可选值和格式要求）。

### 4.2 导入

1. 点「下载模板」拿到该模块的标准模板；
2. 按模板填写数据，**不要修改表头文字**，删除灰色的示例行；
3. 点「导入 Excel」，选择文件，点「开始导入」；
4. 结果会显示：新增 N 条、更新 N 条、跳过 N 条；跳过的行会列出具体原因。

**导入规则**：

| 情况 | 结果 |
|---|---|
| 编号列留空 | 新增一条，自动生成编号 |
| 编号列填写已有编号 | 更新该条记录 |
| 编号列填了不存在的编号 | 跳过并报错 |
| 必填项为空 / 枚举值不合法 / 日期格式错误 | 跳过该行，其他行继续导入 |

**日期格式**：日期 `2026-11-01`，日期时间 `2026-11-01 14:30`。

### 4.3 批量录入的小技巧

想一次录入几十条隐患，最快的方式是：下载模板 → 在 Excel 里填好 → 一次导入。

## 五、数据保存与备份

### 5.1 数据在哪

所有数据保存在 **`data/` 目录**下的 JSON 文件里，每个模块一个文件：

```
data/
├── hazards.json        隐患
├── risks.json          风险点
├── concerns.json       安全疑虑
├── incidents.json      事故
├── trainings.json      培训
├── certificates.json   证照
├── fireEquipments.json 消防设施
├── fireDrills.json     演练
├── contractors.json    承包商
├── equipments.json     设备
├── permits.json        作业票
└── backup/             自动备份
```

### 5.2 备份方式

**方式一（推荐）**：点左下角「备份全部数据」，下载一个 zip 压缩包，里面有全部数据文件。

**方式二**：直接复制整个 `data/` 文件夹到 U 盘或网盘。

**方式三（自动）**：系统每次写数据前，如果距上次备份超过 10 分钟，会自动把原文件复制到 `data/backup/`，每个模块保留最近 20 份。

### 5.3 恢复数据

把备份的 json 文件复制回 `data/` 目录覆盖同名文件，然后**重启工作台**（关闭命令行窗口，重新双击 bat）。

### 5.4 数据安全说明

- 默认只监听本机（127.0.0.1），同一局域网的其他电脑无法访问；
- 使用 `--lan` 启动后局域网可访问，**远程默认只读**，如需密码可加 `--password`；
- 不收集身份证号等敏感信息，人员用姓名 + 工号标识；
- 写入采用「临时文件 + 原子替换」，中途断电不会损坏已有数据；云同步盘占用文件时会自动重试。

## 六、常见问题

**Q：双击 bat 后窗口一闪就没了？**
A：说明启动出错。在该目录按住 Shift + 右键，选「在此处打开 PowerShell 窗口」，运行 `python app\server.py` 查看具体报错。

**Q：页面显示「无法连接本地服务」？**
A：命令行窗口被关闭了，重新双击 `启动工作台.bat`。

**Q：能多个人同时用吗？**
A：可以。用 `启动局域网查看.bat` 启动后，同事在浏览器输入窗口显示的地址就能查看（只读，每 30 秒自动刷新）。如果同事需要录入数据，用 `--lan-edit` 启动。详见 [局域网访问指南](局域网访问.md)。

**Q：数据能导入到别的系统吗？**
A：可以。每个模块都能导出 Excel，`data/*.json` 也是标准 JSON 格式。

**Q：不小心删错了记录？**
A：到 `data/backup/` 找最近的时间戳文件，里面是删除前的完整数据。

**Q：想清空演示数据重新录入？**
A：在目录里打开命令行，运行 `python app\seed.py --clear`，然后重启工作台。

**Q：想重新生成演示数据？**
A：运行 `python app\seed.py --force`（会先清空现有数据，请先备份）。

## 八、扩展与维护

### 加一个字段

只需修改 `app/schema.py` 中对应集合的 `fields` 列表，重启服务即可。列表列、表单控件、Excel 表头、校验规则都会自动跟着变，前端无需改代码。

### 加一个模块

1. 在 `schema.py` 里仿照现有集合写一个 `_xxx()` 函数并加入 `COLLECTIONS`；
2. 在 `web/app.js` 的 `buildNav()` 里加一行导航；
3. 如需 KPI，在 `dashboard.py` 里补充统计。

### 运行自检

```bash
python app\selftest.py          # 后端逻辑（40 项）
python app\httptest.py 8799     # 接口端到端（33 项）
python app\lantest.py 8795      # 局域网/只读（17 项）
node app\uitest.mjs 8801 8800   # 浏览器冒烟（49 项，需先启动服务）
node app\lantest-ui.mjs 8811 8810  # 只读界面（15 项，需以 --lan 启动服务）
```
