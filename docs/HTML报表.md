# HTML 报表导出

把工作台的全部数据和图表导出成**单个 HTML 文件**，双击即可在任意浏览器打开，可离线查看、发邮件、打印成 PDF。

---

## 一、两种导出方式

### 方式一：界面按钮（推荐）

打开看板 → 右上角点 **「导出 HTML 报表」** → 浏览器下载 `.html` 文件 → 双击打开。

导出的是**当前筛选条件**下的数据（如果选了日期范围和部门，报表里就是那个范围）。

### 方式二：命令行

```bash
# 导出到 reports/ 目录（自动命名带时间戳）
python app\export_html.py

# 指定输出路径
python app\export_html.py --out 月度报表.html

# 指定统计范围
python app\export_html.py --from 2026-10-01 --to 2026-10-31 --out 10月报表.html
```

命令行导出后会在窗口显示文件路径和大小。

## 二、报表里有什么

| 区块 | 内容 |
|---|---|
| **核心指标** | 18 个 KPI 卡片：隐患、疑虑、风险、事故、培训、证照、消防、设备、作业票 |
| **数据分析** | 6 个图表：隐患月度趋势、风险四色分布、隐患类别、事故类型、设备分类、疑虑类别 |
| **待办提醒** | 6 类清单：逾期隐患、待处理疑虑、证照到期、消防逾期、设备检验、作业票临期 |
| **台账明细** | 全部 11 个模块的完整表格，带状态彩色徽标 |

### 技术特点

- **单文件**：所有样式、图表全部内联，文件里没有任何外部引用，断网也能看
- **SVG 图表**：矢量图，放大不模糊，打印清晰
- **状态徽标有颜色**：已关闭绿色、待整改橙色、重大隐患红色，一眼看出状态
- **表格可横向滚动**：列多的时候可以左右拖动，鼠标悬停长文本可看全文
- **打印友好**：按 `Ctrl+P` 直接打印或另存为 PDF，会自动隐藏滚动条、避免卡片被切断

## 三、典型用法

### 给领导汇报

1. 看板选好统计范围（如本月）
2. 点「导出 HTML 报表」
3. 把 `.html` 文件发过去，对方双击就能看，不需要装任何东西

### 存档留底

```bash
python app\export_html.py --out "存档\2026年10月安全报表.html"
```

每月跑一次，按月份命名存档。

### 打印成 PDF

打开报表 → `Ctrl+P` → 目标选「另存为 PDF」→ 保存。

建议设置：
- 纸张：A4
- 边距：默认
- 勾选「背景图形」（否则彩色徽标会变成白色）

## 四、和其他导出方式的区别

| 方式 | 适合场景 | 特点 |
|---|---|---|
| **HTML 报表** | 汇报、存档、打印 | 单文件、含全部图表、离线可看、排版好看 |
| **Excel 导出**（各模块） | 继续加工数据 | 只有表格数据，无图表，可在 Excel 里做透视 |
| **备份数据**（左下角） | 系统迁移、数据恢复 | zip 包，包含全部原始 JSON |

## 五、常见问题

**Q：报表文件多大？**
A：113 条数据约 90 KB。数据量到几千条时约 300–500 KB，仍然很轻。

**Q：能直接发给别人吗？**
A：可以，单个 `.html` 文件就是完整报表。注意里面有员工姓名、事故描述等数据，按公司规定管理。

**Q：图表为什么是图片？能改吗？**
A：图表是 SVG 矢量图形，随数据自动生成，不需要手动改。改数据后重新导出即可。

**Q：报表里数据不全？**
A：检查导出时看板的日期范围。如果选的是「本年度」而数据在去年，就不会出现在报表里。点「重置」可导出全部数据。

**Q：能自动定期生成吗？**
A：可以配合 Windows 任务计划程序，定期执行：
```
python app\export_html.py --out "存档\自动报表_%date%.html"
```
